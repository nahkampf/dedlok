Ash & Ember

A dark-only component kit for the cyberpunk client. Graphite and bone do the work; the ember accent is rationed.

Rule 01

Hairlines carry the structure. Borders separate things, not shadows and not fills. Elevation is a step in --bg-*, never a glow.

Rule 02

Bone is the ink; ember is rationed. Primary buttons are white. Ember means live, critical or destructive — aim for about 2% of lit pixels.

Rule 03

Geometry is machined. Radius stays at 0–3px. Character comes from the notched corner (.cut), never from rounding.

Install

Two files plus a font directory, no build step. Drop them into any PHP template — every component is plain markup plus custom properties, so server-rendered HTML needs no JavaScript glue. Every face is self-hosted from public/assets/fonts/ and declared inside the stylesheet, so a page needs no font <link> at all and nothing in the render path leaves this origin. Overpass ships as one variable file per subset, Plex as static instances — three weights per family, split into latin and latin-ext.

markup 
<!-- Every face ships in public/assets/fonts/ and is declared in the stylesheet -->
<link rel="stylesheet" href="/assets/css/ui-kit.css">
<script src="/assets/js/ui-kit.js" defer></script>

Re-skinning

Every component reads from tokens, so you never override a component rule — you override a property, either globally or on one element. A faction, a zone, or a "hacked" state can restyle the whole tree from one selector.

markup 
/* Whole app: a colder faction palette */
:root { --ember: #7FA6D9; --ember-2: #4E6E9E; }

/* One subtree: corporate gold */
.zone-arasaka { --ember: #C9A227; --bg-2: #17150F; }

/* Swap the heading face without touching a component rule */
:root { --font-head: "Oswald", var(--font-label); }

/* One element: a jade health bar at 72% */
<div class="meter" style="--v:.72; --fill:var(--jade)">
  <div class="meter__fill"></div>
</div>

Colour

Nine greys and four signals. The greys are cool and nearly neutral so the ember never has to compete with a coloured ground.

Surfaces & lines
Ink
Signal — use the semantic aliases --ok --warn --crit --info in app code
Ember and brass both read as "attention". If a screen needs more than one warning level, use brass for degrading and ember for failed — never both for the same severity.

Type

Overpass on headings, IBM Plex for everything else. Plex Condensed carries the tracked uppercase labels, the regular sans carries prose, and mono carries anything the machine produced — timestamps, IDs, live values. Overpass descends from Highway Gothic, which keeps headings in the same signage register as the rest of the kit. It ships as a variable font, so the heading scale steps down in weight as well as size.

Headings

Bare <h1>–<h6> are styled directly, so server-rendered markup needs no classes. The .display / .h1 / .h2 / .h3 classes give the same steps when the element has to stay semantically neutral. The scale drops from 700 to 600 as it descends, so hierarchy survives even where two steps sit close in size.

Weight axis

Overpass is shipped as a variable font, so every weight between 100 and 900 costs nothing extra once the file has loaded. Useful for a heading that has to sit quietly, or one that has to shout.

Geometry

The notch is the kit's signature. A clip-path would eat the border, so .cut stacks two clipped pseudo-elements: one for the line, one for the fill inset by 1px.

.cut

Add .cut to any box. Tune with --cut (depth), --cut-line and --cut-fill, or the --alt / --tl modifiers to move the corners.

.cut--clip

A child with its own background will paint over the notched corners and square them off. Add .cut--clip to clip the element itself so children follow the shape. It is not the default because it clips the focus outline too — leave it off on anything focusable.

Brackets & texture

Corner brackets overlay a box without touching its border, so they compose with anything. The grid and scanline utilities are deliberately near-invisible — they should register as texture, not pattern.

Buttons

The primary button is bone, not ember. A white-hot fill on near-black is already the loudest thing on screen, which frees the accent for danger and for live state. .btn--go is the one green button — it means begin, not succeeded, and like ember it is rationed to one per screen. .btn works on <a> as well as <button>; the notched row below uses both.

Captcha

A bare <div class="captcha"></div>. ui-kit.js upgrades it into Cap's <cap-widget> (trycap.dev), reading the endpoint from window.CAP_ENDPOINT and the labels from window.CAP_I18N — so a protected form repeats neither. Inside a <form> the widget injects its own hidden cap-token input, which is what posts. It renders nothing here: no endpoint is configured on this page, and that is the deliberate quiet failure. The widget lives in an open shadow root, so it is styled only through the --cap-* variables mapped onto kit tokens in ui-kit.css. A solved widget proves nothing on its own — the server has to verify the token, which is App\Captcha\Cap and the EnsureCaptchaIsSolved middleware.

Card

The general-purpose surface. .item-card is the loot-specific one; this is for a choice or a summary. .card--select turns it into a radio option — wrap it in a <label> with a hidden radio inside and the whole card becomes the hit target, with a corner tick when chosen. .card__stat rows put a label left and a value right, for effects and modifiers.

Game HUD

Meters are driven by two custom properties and nothing else: --v (a 0–1 ratio, applied as a transform so it animates cheaply) and --fill. PHP can render the value straight into the style attribute.

Readouts & cooldowns

Status effects

Alerts & ticker

The alert banner breathes. It is the loudest thing the kit can do — one per screen, and only when a timer is running against the player. The ticker needs its three-part structure: the tag sits outside the scrolling viewport, and the track holds two identical copies of the feed — the animation shifts it by exactly half its width, so a single copy would scroll off and leave a gap.

Terminal

Log lines are timestamp / level / message. The scrollback fades at the top instead of ending on a hard cut. Pressing Enter in the prompt emits a ui:command event on the .term element — wire that to your PHP endpoint.

Log feed

The demo below is live: UI.log() appends lines and type anything into the prompt.

Typed reveal

UI.type(el, text) types character by character and resolves a promise, so you can chain dialogue beats. The pure-CSS .typewriter variant needs no JS if the string is fixed.

Inventory

Five rarity tiers, all inside the palette — no rainbow. Each tier is a class that sets --tier, so slots, list rows and tooltips agree without repeating a colour anywhere.

Tiers

Slot grid

Slot states: empty, filled, selected, locked, and drop-target. Quantity and durability sit inside the slot so the grid stays square at any column count.

Item card & rows

Corner tick

.ticked marks a box as one you already have, and touches nothing else — no border colour, no background, no layout. It is the same device .card--select uses for a chosen option and .slot--filled for an occupied socket, which is why it is a modifier rather than a fourth copy of it. --tick sets the colour and --tick-size the leg; the default is --ok, since the thing it says is "you have this". Pair it with .meter--seg to show how far along the thing is.
